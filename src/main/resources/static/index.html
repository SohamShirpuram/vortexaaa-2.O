ℹ️ About GovFix — Smart Civic Services

Configurable Civic Grievance & Municipal Workflow Management Engine

12-Hour Hackathon Prototype

The Problem & Our Solution

Municipal complaint portals often suffer from lack of accountability, where tickets are closed prematurely without verified proof, or left pending indefinitely when junior engineers face delays.

GovFix solves this by implementing a deterministic state-machine workflow engine coupled with role-enforced transitions, mandatory before-and-after photographic evidence, automatic SLA deadline escalations, and live GPS sanitation van tracking.

5 Core Proposed Improvements:

  1. Unified Citizen Dashboard: Single view combining real-time municipal grievance KPIs and service redirection.
  2. Smart Complaint Tracking: Visual lifecycle stepper tracking tickets from submission to closure.
  3. AI-Assisted Routing with Human Approval: Automated category and priority triage where decisions require officer sign-off.
  4. Automated SLA Deadline Escalation: Automated background triggers alerting executive engineers when stage deadlines expire.
  5. Verified Resolution & GPS Fleet Tracking: Mandatory field inspection proof and live vehicle route monitoring.

Technology Architecture

  • ☕ Backend: Java 21, Spring Boot 3, Spring Web
  • 🛡️ Security: Spring Security (Role-enforced API boundaries)
  • 🗄️ Database: MySQL 8 / Persistent SQL Storage with JPA/Hibernate
  • 🌐 Frontend: HTML5, CSS3, Vanilla JavaScript, Fetch API
  • 🗺️ Maps: Leaflet + OpenStreetMap (Live GPS Simulation)
  • 🎨 3D Graphics: Three.js (Procedural Civic Cityscape & Truck)
  • 🏛️ Design System: Inspired by USA.gov & PCMC Guidelines
⚠️ Disclaimer: GovFix is an independent hackathon prototype inspired by PCMC municipal services. It does not claim official government endorsement or live municipal server integration.
